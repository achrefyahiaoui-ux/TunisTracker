# TunisTracker

متابعة إنجاز المخططات السنوية للتعليم الابتدائي — مقسّمة حسب السنة والمادة:

- **السنة الأولى:** اللغة العربية (8 وحدات)، الرياضيات (6 فترات)، الإيقاظ العلمي (4 فترات)
- **السنة الثالثة:** اللغة العربية (8 وحدات)، الرياضيات (5 فترات)، الإيقاظ العلمي (4 فترات)، التربية الإسلامية (5 فترات)

الملفات:
- `index.html` — صفحة المتابعة (ملف واحد، بدون أي تبعيات).
- `plan.json` — محتوى المخططات كما هو في الكتاب (الحصص + التقييم لكل فترة/وحدة).

يُحفظ التقدم في المتصفح (localStorage) والمرفقات في IndexedDB على نفس الجهاز. استعمل زر «نسخة احتياطية» لنقل البيانات إلى جهاز آخر.

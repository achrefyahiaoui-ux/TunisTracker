- **السنة الثالثة:** اللغة العربية (8 وحدات)، الرياضيات (5 فترات)، الإيقاظ العلمي (4 فترات)، التربية الإسلامية (5 فترات)، التربية التشكيلية، التربية التكنولوجية، التربية الموسيقية
- **السنة الرابعة:** اللغة العربية (8 وحدات)، الرياضيات (5 فترات)، الإيقاظ العلمي (4 فترات)، التربية الإسلامية (4 فترات)، التربية التشكيلية، التربية التكنولوجية، التربية الموسيقية
- **السنة الخامسة:** اللغة العربية (8 وحدات)، الرياضيات (5 فترات)، الإيقاظ العلمي (4 فترات)، التربية الإسلامية (4 فترات)، التاريخ (3 فترات)، الجغرافيا (4 فترات)، التربية المدنية (5 فترات)، التربية التشكيلية، التربية التكنولوجية، التربية الموسيقية

الملفات:
- `index.html` — صفحة المتابعة (ملف واحد، بدون أي تبعيات).
- `plan.json` — محتوى المخططات كما هو في الكتاب (الحصص + التقييم لكل فترة/وحدة).

يُحفظ التقدم في المتصفح (localStorage) والمرفقات في IndexedDB على نفس الجهاز. استعمل زر «نسخة احتياطية» لنقل البيانات إلى جهاز آخر.
